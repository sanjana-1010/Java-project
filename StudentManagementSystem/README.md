# Smart Campus – Student Performance & Coaching Management System

## Project Description
Smart Campus is a Core Java-based application designed to manage student information, academic performance and coaching activities.

## Features
- Add and register students
- Update and remove student details
- Search students by name
- Display student records
- Identify top 3 performers
- Attendance alerts
- Course-wise performance reports
- Performance analysis
- Generate student report cards
- Save and retrieve student data using file handling
- Duplicate student validation using custom exception handling

## Technologies Used
- Core Java
- Object-Oriented Programming
- HashMap and ArrayList
- Exception Handling
- File Handling
- Serialization

## How to Run
1. Import the StudentManagementSystem project into Eclipse.
2. Open `Main.java`.
3. Run it as a Java Application.
