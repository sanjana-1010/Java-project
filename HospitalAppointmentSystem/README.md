# Hospital Appointment Management System

## Project Description
MediCare Pro is a Core Java-based application designed to manage hospital patients, doctors and appointments.

## Features
- Patient registration and management
- Doctor registration and management
- Book and cancel appointments
- View available appointment slots
- View doctor schedules
- View patient appointment history
- Search patients and doctors
- Generate hospital and patient reports
- Smart doctor recommendation
- Save data using file handling and serialization

## Technologies Used
- Core Java
- Object-Oriented Programming
- HashMap and ArrayList
- Exception Handling
- File Handling and Serialization
- Java Date and Time API

## How to Run
1. Import the project into Eclipse.
2. Open the `Main.java` file.
3. Run it as a Java Application.
