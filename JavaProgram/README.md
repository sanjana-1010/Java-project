# Core Java Programming

## Project Description
This project contains Java practice programs developed using Eclipse IDE to understand and practise Core Java concepts.

## Topics Covered
- Arrays
- Object-Oriented Programming
- Constructors
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
- Interfaces
- Exception Handling
- Collections Framework
- Multithreading
- String Handling
- Wrapper Classes
- File Handling
- Java 8 Features

## Technologies Used
- Java
- Eclipse IDE

## How to Run
1. Import the JavaProgram project into Eclipse.
2. Open the required Java file.
3. Run the program as a Java Application.
